# Groq AI Implementation Plan

Goal: Add server-only Groq credentials and connect the app's existing writing tools.
Architecture: One bounded, authenticated server endpoint shared by Vite development and Vercel. Browser preferences contain only provider and model; a separate app access password lives in memory for the current visit.
Tech stack: Existing React/TypeScript, Node HTTP, native fetch, Node test runner, Playwright.
Spec: ../specs/2026-11-08-groq-ai-design.md (approved by user).

## Constraints and review focus

Never send Groq credentials to the browser or log resume content. Require a separate app access password so a public URL cannot freely spend the owner's quota. Fail closed when unconfigured. Preserve resume identity and structure when validating optimization results. Bound input and timeouts. Treat model output as untrusted text. Keep offline fallback explicit.
